# React Demo

Demo cac React Hooks.

## Cai dat

```bash
npm install
npm run dev
```

Chay o http://localhost:5173

## Backend

Can chay backend truoc o http://localhost:3000

## Demo

1. useState - counter, form, state lifting
2. useEffect - dependency array, cleanup
3. useMemo - cache tinh toan
4. useCallback - memo function
5. useRef - dom, previous value
6. useContext - context api
7. Component patterns
8. API demo - goi backend
