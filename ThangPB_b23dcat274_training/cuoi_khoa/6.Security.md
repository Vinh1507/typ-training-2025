### Dựng HAProxy Loadbalancer
1. **Dựng HAProxy Loadbalancer**
- Sử dụng 1 con VM
   - Cấu hình ip tĩnh: `192.168.1.125`
- Cài đặt HAProxy:
```
sudo apt update
sudo apt install haproxy -y
```
- Cấu hình HAProxy:
```
global
    log /dev/log local0
    log /dev/log local1 notice
    daemon
    maxconn 4096

defaults
    log global
    mode tcp
    option tcplog
    timeout connect 5s
    timeout client  60s
    timeout server  60s

listen stats
    bind *:8404
    mode http
    stats enable
    stats uri /stats

frontend frontend_http
    bind *:80
    mode http
    redirect scheme https code 301

frontend frontend_https
    bind *:443
    mode tcp
    default_backend backend_ingress_https

backend backend_ingress_https
    mode tcp
    balance roundrobin
    option tcp-check
    server k8s-master 192.168.1.120:30332 check
    server k8s-worker 192.168.1.121:30332 check
```
2. **Sử dụng Ingress**
- Cài đặt Ingress Controller
```
kubectl apply -f https://raw.githubusercontent.com/kubernetes/ingress-nginx/controller-v1.8.1/deploy/static/provider/baremetal/deploy.yaml
```
- Tạo TLS Certificate
```
openssl genrsa -out tls.key 2048
openssl req -new -key tls.key -out tls.csr -subj "/C=VN/ST=Hanoi/L=Hanoi/O=TYP/CN=*.typ-app.local"
openssl x509 -req -in tls.csr -signkey tls.key -out tls.crt -days 365 -extensions v3_req
```
- Tạo Kubernetes Secret
```
kubectl create secret tls typ-tls-secret \
  --cert=tls.crt \
  --key=tls.key \
  -n typ-app
```
- Cấu hình Ingress
   - Backend ingress: [ingress](https://github.com/Phamthang-25/typ-backend/blob/main/backend-chart/templates/ingress.yaml)
   - Fronted ingress: [ingress](https://github.com/Phamthang-25/typ-frontend/blob/main/frontend-chart/templates/ingress.yaml)

### Yêu cầu 3
Sử dụng 1 trong số các giải pháp để rate limit cho Endpoint của API Service, sao cho nếu có quá **10 request trong 1 phút** gửi đến Endpoint của API service thì các request sau đó bị trả về **HTTP Response 409**.

- **Sử dụng giải pháp ở HAProxy**
- Cấu hình HAProxy:
```
global
    daemon
    maxconn 4096
    log stdout local0

defaults
    mode tcp
    timeout connect 5000ms
    timeout client 50000ms
    timeout server 50000ms
    option tcplog
    log global
listen stats
    bind *:8404
    mode http
    stats enable
    stats uri /stats
frontend frontend_http
    bind *:80
    mode http
    redirect scheme https

frontend frontend_https
    bind *:443
    mode tcp
    default_backend backend_ingress_https

frontend api_proxy
    bind *:8080
    mode http
    option httplog
    
    
    stick-table type ipv6 size 100k expire 60s store http_req_rate(60s)
    
    
    http-request track-sc0 src
    
    
    http-request return status 409 content-type "application/json" string '{"error":"Rate limit exceeded","message":"Maximum 10 requests per minute allowed","code":429}' if { sc_http_req_rate(0) gt 10 }
    
    default_backend api_backend

backend api_backend
    mode http
    balance roundrobin
    option httpchk GET /actuator/health
    
    server api1 192.168.1.121:30081 check inter 5s fall 3 rise 2

backend backend_ingress_https
    mode tcp
    balance roundrobin
    server k8s-node1 192.168.1.121:30332 check
```
