- Tìm hiểu:
  - `Ansible Configuration(ansible.cfg)`
  - `Inventory`
  - `Ad-Hoc commands trong Ansible`
  - `Playbook`
  - `Task`
  - `Module`
  - `Role`

## 2. Thực hành
- `Viết playbook deploy 1 project bất kỳ:
Source code của project cần đẩy trước lên git hoặc đóng gói trong container đẩy lên resgitry(Docker Hub, Nexus, Habour,...) và viết ansible task để pull về (từ git hoặc từ registry), khuyến khích thực thi nhiều task có tính idempotent`
